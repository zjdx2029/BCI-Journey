#BIC-Journey: My Path to Brain-Computer Interface

##About Me
- Sophomore, Computer Science, Zero background in hardware.
- Goal: Postgraduate research in BCI, Computational Neuroscience, and Cognitve Neuroscience.

##Project Goal
BUild a complete bio-signal acquisition pipeline:
[Sensor] -> [Arduino Nano] -> [Serial Port] -> [Python] -> [Real-time Plot]

- Arduino Nano (ATmega328P, serial output)
- AD8232 (ECG/Bio-signal sensor)
- Dupont wires (female-female)
- Soldering iron kit (14 pieces)

##Software
- OS: Ubuntu
- Hardware: Arduino IDE (C++ for data streaming)
- Upper Computer: Python 3 (pyserial, numpy, matplotlib, pandas)

##Roadmap
- [] Step 1: Build hardware circuit, draw real-time ECG waveform.
- [] Step 2: Signal filtering (50HZ notch filter, band-pass) & data cleaning.
- [] Step 3: Transition to EEG (MNE-Python, Kaggle datasets).
- [] Step 4: Decoding algorithms (Scikit-learn / PyTorch).
- [] Step 5: Explore cognitive tasks (e.g., attention, memory) using EEG data.
